# 🍕 Pizza Ordering Vibe Project

Welcome to the **Pizza Ordering Vibe Project**! This is a visually engaging pizza ordering website designed to explore and master the art of HTML and CSS.

## 🎯 Implementation Goals

This project is a "vibe coding" experiment focused on:
-   **Pure HTML & CSS**: Building a beautiful implementation without relying on JavaScript frameworks initially.
-   **Learning Journey**: Improving HTML structure and CSS styling techniques.
-   **Future Development**: JavaScript functionality will be added in later stages to bring the interactive elements to life.

## ✨ Features

The project currently includes the following pages, designed with a premium and dynamic aesthetic:

-   **🏠 Home (`index.html`)**: The landing page with a welcoming vibe.
-   **📜 Menu (`src/menu.html`)**: A showcase of available pizzas.
-   **🎨 Customizer (`src/customizer.html`)**: interface for building your own pizza.
-   **🛒 Cart & Checkout (`src/cart.html`)**: Reviewing orders and "checking out".
-   **🚚 Order Tracker (`src/tracker.html`)**: A visual status tracker for your delivery.
